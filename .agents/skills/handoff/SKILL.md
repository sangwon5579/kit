# handoff

## 절차
1. `git log --oneline`, `docs/PLAN.md`, `docs/TRACEABILITY.md`, `docs/VERIFICATION.md`, 코드 구조를 확인한다.
2. `docs/HANDOFF.md` 템플릿을 채운다. 규칙:
   - 완료 / 미완 / 알려진 이슈는 코드와 테스트 결과로 확인된 것만 적는다. 확인되지 않은 것은 "미확인"으로 표시한다.
   - 과장하지 않는다. "완벽", "모든", "항상" 같은 표현을 쓰지 않는다.
   - "다음 할 일"은 우선순위와 예상 난이도를 포함한다.
   - "AI 활용 요약"에는 무엇을 위임했고 무엇을 내가 직접 결정·검증했는지 구분해서 적는다.
3. `README.md`의 실행 방법을 실제로 따라 실행해(기존 서버와 다른 포트로) 맞는지 확인한다. 틀리면 README 수정안을 낸다.
4. 수정안을 보여주고 내가 확인하면 파일에 반영한다.
