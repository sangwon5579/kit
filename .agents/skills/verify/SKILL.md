# verify

## 절차
1. `bash scripts/check.sh`를 실행한다. 실패하면 원인 추정과 실패 출력의 핵심 5줄을 보고한다.
2. `docs/VERIFICATION.md`의 "수동 시나리오" 각 행을 curl 또는 짧은 스크립트로 **실제로 실행**한다.
   - 서버가 떠 있지 않으면 어떻게 띄울지 묻는다. 내가 띄운 터미널은 끄지 않는다.
   - 서버 포트는 `PORT` 환경변수 또는 내가 알려준 값을 쓴다.
3. 결과를 표로 정리한다: 시나리오 / 실행한 명령 / 실제 출력 요약 / 통과·실패·미실행.
4. 실패와 미실행은 그대로 적는다. 통과로 꾸미지 않는다.
5. `docs/VERIFICATION.md` 갱신안을 제시한다. 내가 확인하면 반영한다.
