# plan-draft

## 역할
코드를 쓰기 전에 계획을 세우는 단계다. 이 스킬을 쓰는 동안 코드는 작성하지 않는다.

## 절차
1. `README.md`, `docs/INTERVIEW.md`, `docs/PLAN.md`(템플릿)를 읽는다.
2. `docs/PLAN.md`의 각 절을 채운 초안을 제시한다. 조건:
   - **문제 정의**: 담당자의 표현을 그대로 인용한 문장 1개 이상 포함
   - **성공 기준**: "무엇을 / 어떻게 확인 / 기준값" 형태로, 실행해서 확인할 수 있게
   - **범위 Out**: "하지 않을 것" 3개 이상, 각각 왜 안 하는지 한 줄
   - **접근과 구조**: 선택지 2개 + 트레이드오프 → 추천 1개. 내가 확인하기 전에는 구현하지 않는다
   - **작업 분해**: 5개 이하. 각 작업에 완료 조건, 검증 방법, 예상 시간(분). T1은 항상 "스캐폴드 + /health + 테스트 1개"
   - **리스크**: 3개와 대응
3. 확실하지 않은 가정은 `가정:`으로 표시하고, 담당자에게 물어볼 질문 목록을 따로 낸다.
4. 내가 확인하면 `docs/PLAN.md`에 반영한다. 반영 후 "9. 변경 이력"에 첫 줄을 남긴다.
